= Bonita Process Designer Documentation
:toc: macro

This repository is the https://antora.org[Antora] documentation component for
**Bonita Process Designer** — the web-based BPMN diagram editor. It contains the
end-user, installation, and administration guides that are published as part of
the Bonita documentation site.

toc::[]

== Component overview

The component is declared in `antora.yml`:

* *name*: `bonita-process-designer`
* *title*: Bonita Process Designer
* *version*: `1.0`

Shared attributes (product name, Bonita version, customer portal URL, pagination
settings) are defined under `asciidoc.attributes` in `antora.yml` and are
available in every page via attribute references such as `{productName}`.

== Structure

Content is split into Antora *modules*, each living under `modules/<module>/`
with its pages in `pages/` and a navigation file at the module root:

[cols="1,3"]
|===
| Module | Contents

| `ROOT`           | Landing page, FAQ, release notes, resources
| `getting-started`| First steps, interface overview, first diagram, AI generation intro
| `installation`   | Docker / standalone / Bonita-Runtime installs, first-time setup, configuration
| `user-guide`     | Editing, BPMN elements, collaboration, comments, labels, versioning, AI, simulation, marketplace, export/import
| `administration` | Permissions and roles, user/group management, settings, AI quota, license
| `how-tos`        | Task-oriented walkthroughs
|===

The component currently ships *38 content pages* across these six modules.
Navigation trees live in `modules/ROOT/nav.adoc` and
`modules/<module>/<module>-nav.adoc`, all wired into `antora.yml`.

== Contributing

* *File names*: use lowercase `kebab-case`, e.g. `create-your-first-diagram.adoc`.
  Place new pages under `modules/<module>/pages/`.
* *Page header*: start every page with a level-0 title and a `:description:`
  attribute, then reuse it as the lead paragraph:
+
[source,asciidoc]
----
= Page title
:description: One-sentence summary of the page.

{description}
----
* *Cross-references*: link between pages with `xref:`. Within the same module use
  a bare target (`xref:labels.adoc[Labels]`); across modules qualify with the
  module name (`xref:administration:application-settings.adoc[Settings]`).
* *Navigation*: add every new page to the relevant `*-nav.adoc` so it is
  reachable from the menu, and register any new module's nav file in `antora.yml`.
* *Avoid stale stack references*: this product runs on Spring Boot + PostgreSQL.
  Do not mention MongoDB, Express, Mongoose, or LicenseSpring.

== Building

This component is not built in isolation. It is consumed by the
**bonita-documentation-site** Antora playbook, which aggregates it with the other
Bonita components and renders the full site. Add this repository as a content
source in that playbook, then run the site build there to preview the rendered
output locally.
