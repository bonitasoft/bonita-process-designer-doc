= Organize diagrams with labels
:description: Use labels to categorize your diagrams and filter the home dashboard, and learn how the single featured label shapes the default view.

{description}

Labels are a simple way to organize the diagrams in your groups. Each label has a name and a colour, and a single diagram can carry several labels at once — for example a diagram could be tagged both `HR Process` and `Finance`. Labels make it easy to group related processes and to narrow down a long list of diagrams to just the ones you care about.

Every user can see the labels available in {productName} and use them to filter. Creating, renaming, recolouring and deleting labels is reserved for administrators — see xref:administration:application-settings.adoc[the administration guide] for managing the label catalogue.

== Assign labels to a diagram

If you have the Creator or Admin role for a diagram's group, you can assign labels to it. A Reader can see the labels on a diagram but cannot change them.

. Open the diagram, or use the diagram's options on the home dashboard.
. Open the label selector. Labels are presented as a checklist of all available labels.
. Tick the labels you want to apply and untick the ones you want to remove. You can select as many labels as you need.
. Confirm. The diagram's labels update immediately and the new tags appear on the diagram card.

== The featured label

One label in the catalogue can be marked as *featured*. Only a single label can be featured at any time — when an administrator marks a label as featured, any previously featured label is automatically un-featured.

The featured label changes what you see when you open the home dashboard. Instead of opening straight to *all* diagrams, the dashboard surfaces a dedicated section of diagrams that carry the featured label, with a banner naming it. This steers everyone toward the processes that matter most at a given moment.

What you see alongside the featured section depends on your role:

* As a Reader you see the featured diagrams and a button to browse the other diagrams you have access to.
* As a Creator or Admin you see the featured section and the full list of diagrams below it.

You can always reach every diagram you have access to by browsing the other diagrams or by changing the dashboard filter (see below).

== Filter the dashboard by label

On the home dashboard you can filter the diagram grid by label to focus on a single category.

. Go to the home dashboard.
. Choose a label from the label filter. The grid updates to show only diagrams that carry that label.
. Select the option for all labels to clear the filter and see every diagram you have access to.

== Who manages labels

The label catalogue is managed by administrators. Administrators can create labels, rename them, change their colour, mark one as featured, and delete labels. Deleting a label that is in use removes it from every diagram that carried it. For details, see xref:administration:application-settings.adoc[Application settings].
