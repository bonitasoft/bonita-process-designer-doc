= Organize diagrams with labels
:description: Use labels to categorize your diagrams and filter the home page, learn what the featured label changes, and choose between labels and folders.

{description}

Labels are a simple way to categorize the diagrams in your groups. Each label has a name and a color, and a single diagram can carry several labels at once — for example a diagram could be tagged both `HR Process` and `Finance`. Labels make it easy to group related processes and to narrow down a long list of diagrams to just the ones you care about.

Every user can see the labels available in {productName} and use them to filter. Creating, renaming, recoloring and deleting labels is reserved for administrators — see xref:administration:manage-labels.adoc[Manage labels] for managing the label catalog.

[#assign-labels]
== Assign labels to a diagram

If you have the Creator or Admin role for a diagram's group, you can assign labels to it. A Reader can see the labels on a diagram but cannot change them.

. On the home page, open the diagram card's menu (the three dots) and select *Edit labels*. In the editor, use *Edit Labels* in the diagram information panel.
. The *Edit Labels* dialog lists all available labels as a checklist.
. Select the checkboxes of the labels you want to apply, and clear the ones you want to remove. You can select as many labels as you need.
. Select *Save*. The diagram's labels update immediately and appear on the diagram card.

[#filter-by-label]
== Filter the home page by label

The home page shows a row of label chips above the diagrams: *All Diagrams* first, then one chip per label.

. Select a label chip. Only the diagrams that carry that label are shown, and the section title shows the label's name.
. Select *All Diagrams* to clear the filter and see every diagram you have access to.

The label filter applies to the diagram cards, to the Tree view and to the search results, on every level of the home page. It combines with the *Group:* and *My processes* filters. Folder tiles are not filtered by label. For all the filters, see xref:user-guide:managing-diagrams.adoc#filter[Manage diagrams].

[TIP]

[#featured-label]
== The featured label

An administrator can mark one label of the catalog as *featured*. Only a single label can be featured at any time — when an administrator marks a label as featured, any previously featured label is automatically un-featured.

The featured label changes two things on the home page, for every user:

* its chip is placed right after *All Diagrams*, ahead of the other labels;
* it is the filter already selected when you open the home page, so you first see the diagrams that carry it.

Select *All Diagrams* at any time to see every diagram you have access to.

[#labels-or-folders]
== Labels or folders?

Labels and xref:user-guide:organize-processes-in-folders.adoc[folders] both help you organize processes, in different ways:

[cols="1,2,2"]
|===
| |Labels |Folders

|Who manages them
|Admins manage one catalog, shared by all groups. Creators and Admins apply labels to diagrams.
|Creators (in their groups) and Admins create, rename, move and delete folders.

|Scope
|Global: the same labels are available in every group.
|Per group: a folder belongs to one group, and only holds processes of that group.

|Per diagram
|Several labels on the same diagram.
|One filing place: Home, a folder, or under another process.

|Use it to
|Filter by a cross-cutting theme, such as a business domain or a status: on the level you are on, in the *Tree* view, or in search results.
|Give processes a place to live, and browse them level by level.
|===

The two combine: select a label chip inside a folder to see only the diagrams of that folder that carry the label.

[#who-manages-labels]
== Who manages labels

The label catalog is managed by administrators. Administrators can create labels, rename them, change their color, mark one as featured, and delete labels. Deleting a label that is in use removes it from every diagram that carried it. For details, see xref:administration:manage-labels.adoc[Manage labels].
