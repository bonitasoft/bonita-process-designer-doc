= Application settings
:description: Configure the application-wide settings that control self-registration, autosave timing, and AI prompt length in {productName}.

{description}

Application settings are global options that apply to your whole {productName} instance. They control whether visitors can register their own account, which role those accounts get, how often diagrams autosave, and how long AI generation prompts may be.

[IMPORTANT]
====
Only users with the *Admin* role can view and change application settings. Other users never see these options.
====

== Where to set them

Open the *Admin* panel and go to the *Settings* section. Each setting below has its own field. Change the values you need and save. Updated values take effect immediately for new actions (for example, the next autosave or the next AI generation request).

image::admin-settings.png[The Settings section of the admin panel,800]

== Available settings

[options="header",cols="1,1,1,1,3"]
|===
| Setting | Type | Range | Default | Description

| Allow self-registration
| Boolean
| On / Off
| Off
| When enabled, a registration link appears on the login page so visitors can create their own account. When disabled, only an Admin can create accounts. See xref:user-management.adoc[Manage users].

| Default registration role
| Choice
| `Reader` or `Creator`
| `Reader`
| The role assigned to accounts created through self-registration. Choose `Reader` for view-only access or `Creator` to let new users create and edit diagrams in their groups. Has no effect when self-registration is off.

| Autosave interval
| Number (seconds)
| 1–300
| 5
| How often the editor automatically saves the open diagram while you work. A lower value saves more frequently; a higher value reduces background saves.

| AI prompt maximum length
| Number (characters)
| 200–2000
| 500
| The maximum number of characters allowed in a natural-language description used for xref:user-guide:ai-generation.adoc[AI diagram generation].
|===

The application validates every value against its allowed range when you save. A value outside the range is rejected, and the previous setting is kept.

[NOTE]
====
The *Default registration role* never grants Admin rights. New self-registered users can only be a `Reader` or a `Creator`. To promote an account to Admin, change its role in xref:user-management.adoc[Manage users].
====
