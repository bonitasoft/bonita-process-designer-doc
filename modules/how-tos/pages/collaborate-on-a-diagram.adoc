= Collaborate on a diagram
:description: Edit the same {productName} diagram together with teammates in real time, with live cursors and presence.

{description}

This recipe walks you and your teammates through co-editing one diagram at the same time. The key requirement is that everyone belongs to the same group as the diagram, because diagram access in {productName} is scoped to groups.

== Before you start

* Everyone who needs to edit must have an account with the **Creator** or **Admin** role. A **Reader** can open the diagram and follow along, but cannot make changes.
* The diagram must belong to a **group**, and every participant must be a member of that group. Non-members cannot see or open the diagram at all.

For the full role matrix, see xref:user-guide:real-time-collaboration.adoc[Collaborate in real time].

== Steps

. **Confirm group membership.** An Admin adds each teammate to the group that owns the diagram. A non-member is completely isolated from the diagram, so this step must come first.

. **Edit together.** Add, move, resize and connect elements as usual. Every change is broadcast to the other participants and appears on their canvas within moments — no manual refresh is needed.
. **Save when you reach a milestone.** The server stores the shared diagram a few seconds after the last change, so nobody has to save for the others to see the work. *Save* (or *Ctrl+S*) makes the server store it immediately and refreshes its preview on the Home page; it never overwrites your teammates' changes with your copy.

== How conflicts are handled

The server is the authoritative store for the diagram. When two people change the same element at nearly the same moment, the **last change wins**, and that result is shown to everyone. To avoid surprises, work on different parts of the diagram so that two people are not reshaping the same element at once.

An advisory lock indicator can show that someone is actively editing, but it does not stop concurrent editing; it is a courtesy signal, not a hard lock.

== When one of you uses AI

While a teammate generates or modifies the diagram with AI, everyone else is paused: the editor shows *AI is editing this diagram for <name> — editing is paused until it finishes.* Wait for the banner to disappear, then carry on. Analyzing the diagram with AI does not pause anyone. See xref:user-guide:real-time-collaboration.adoc#ai-editing-lock[While AI is editing the diagram].

== If you lose connection

If your network drops, the editor reconnects automatically and your canvas is replaced by the current version held by the server. Any changes made by others while you were offline appear once you are back; changes you made while disconnected can be lost if others kept editing. Re-check the canvas before continuing so you are working from the current state.

If the editor shows *Live collaboration stopped after repeated connection failures. Reload the page to resume.*, reload the page. Reload it too after a Wi-Fi drop or when your computer wakes from sleep: a connection that died silently can still look connected. See xref:user-guide:real-time-collaboration.adoc#connection-problems[When the connection drops].
